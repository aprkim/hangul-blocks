# 한글 조립 게임 — P0 / P1 스펙

구현 스펙. P0부터 순서대로. P1 통과 전에는 P2 이후 항목을 만들지 않는다.

---

## 1. 대상과 목표

- **사용자:** 만 4세. 한국어 구어 유창, 영어 구어 유창, **한글 해독 불가**
- **문제:** "한국어 배우기"가 아니라 **소리 → 글자 매핑**
- **핵심 체험:** 자모를 조립하면 그 자리에서 소리가 난다
- **성공 기준:** 아이가 **스스로** 10분 이상 붙어 있고, 다음 날 또 열어달라고 한다

### 범위 밖 (P0/P1에서 만들지 않음)

계정·로그인, 백엔드, 점수·별·레벨, 종성(받침), 쓰기/획순, 받아쓰기, 앱스토어 배포, 영어 UI 토글, 다중 사용자 프로필, 애니메이션 캐릭터

---

## 2. 스택

| 항목 | 선택 |
|---|---|
| 프레임워크 | Vite + React + TypeScript, 단일 페이지, 라우터 없음 |
| 스타일 | Tailwind |
| 상태 | React state만. 전역 스토어 없음 |
| 저장 | 없음 (P3에서 localStorage) |
| 오디오 | HTML5 `Audio`, 전체 프리로드, mp3 |
| 폰트 | Pretendard 또는 나눔스퀘어라운드 (받침 없는 글자가 깔끔한 둥근 고딕) |
| 배포 | Vercel 또는 Netlify, 정적 |

### 타깃 환경

**iPad Safari 가로 모드가 1순위.** 데스크톱은 동작만 하면 됨.

- 스크롤 없음. 화면 하나에 전부 들어가야 함
- 터치 타깃 최소 **120px** (4세 손가락 기준, WCAG 44px보다 훨씬 크게)
- iOS 오디오 정책: 첫 사용자 탭에서 오디오 컨텍스트 unlock 필요
- 더블탭 줌, 길게 눌러 선택, 고무줄 스크롤 전부 차단

---

## 3. 자모 세트

**기본 자음 14개:** ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ
**기본 모음 10개:** ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ

쌍자음(ㄲ ㄸ ㅃ ㅆ ㅉ), 복합모음(ㅐ ㅔ ㅘ ㅝ ...), 받침은 P0/P1에 넣지 않음.

### 중요 결정: 자음은 **이름이 아니라 음가**로

탭했을 때 "기역"이 아니라 **"그"** 가 나와야 한다. 조립의 전제가 음가이기 때문. `ㄱ` + `ㅏ` 를 "기역아"로 배우면 "가"가 안 나온다.

- 탭 → 음가 ("그", "느", "드" ...)
- 이름(기역, 니은)은 P2 이후. 지금은 아예 노출 안 함

---

## 4. P0 — 자모판

가장 단순한 화면. 이걸 먼저 붙여서 아이 반응을 본다.

### 레이아웃

- 상단 영역: 자음 14개
- 하단 영역: 모음 10개
- 둘 다 격자. 가로 모드에서 스크롤 없이 전부 보여야 함
- 자음과 모음은 **색으로 구분** (색 두 개면 충분)

### 동작

- 타일 탭 → 해당 음가 오디오 재생 + 타일 스케일 업/바운스
- 재생 중 다른 타일 탭 → 즉시 이전 오디오 중단하고 새 오디오 재생
- **잠금 없음, 순서 없음, 점수 없음.** 자유 탐색만
- 화면 전환 버튼 하나 (P1 조립판으로). 아이콘만, 텍스트 없음

### P0 판단 기준

아이가 타일을 스스로 반복해서 누르는가. 어른이 "눌러봐"라고 유도해야만 누르면 신호가 나쁜 것.

## 5. P1 — 조립판

핵심 화면. 여기서 재미없으면 프로젝트 중단.

### 레이아웃

```
        [ 글자 틀 ]        ← 상단 중앙, 크게
   ─────────────────────
   자음 트레이 (격자)
   모음 트레이
                   [ 리셋 ]
```

### 글자 틀 — 가로모임 / 세로모임 전환

**이게 이 앱의 교육적 핵심이다.** 선택한 모음에 따라 초성 자리가 움직인다.

| 모음 | 배치 | 예 |
|---|---|---|
| ㅏ ㅑ ㅓ ㅕ ㅣ | 가로모임 — 초성 왼쪽, 중성 오른쪽 | 가, 너 |
| ㅗ ㅛ ㅜ ㅠ ㅡ | 세로모임 — 초성 위, 중성 아래 | 고, 무 |

- 모음을 바꾸면 초성 자리가 **애니메이션으로 이동** (순간 점프 금지). 이 이동이 "모양이 바뀌는 이유"를 몸으로 가르친다
- 자음만 놓인 상태에서는 기본 가로모임 자리에 놓고 중성 자리를 점선으로 표시

### 조작

- **탭-탭 방식을 기본으로** 구현 (자음 탭 → 초성 자리에 들어감, 모음 탭 → 중성 자리에 들어감)
- 드래그는 추가 옵션. 4세 iPad 드래그 정확도가 낮으므로 드래그만 지원하면 안 됨
- 이미 채워진 자리에 같은 종류를 탭하면 **교체**
- 두 자리가 다 채워지면: 완성 글자를 틀에 렌더 + 합성 음절 오디오 재생 + 가벼운 축하 모션(0.5초 이내)

### 틀린 답이 없다

**모든 조합이 유효하고 모두 소리가 난다.** `ㄱ+ㅡ` = "그", `ㅎ+ㅠ` = "휴". 실제 단어가 아니어도 재생한다.

- "땡" 소리, 빨간 X, 흔들림 피드백 **금지**
- 실패 상태가 없으므로 아이가 겁내지 않고 조합을 탐색한다. 이게 자모 원리를 체득하는 경로

### 리셋

큰 아이콘 버튼 하나. 두 자리 모두 비움. 확인 다이얼로그 없음.

---

## 6. 오디오

전체 파일 목록과 녹음 가이드는 `AUDIO.md` 참조.

구현 시 전제:

- **자모 음원을 이어 붙여 음절을 만들지 않는다.** "그아"로 들린다. 음절은 별도 파일
- **P1은 자음 4개(ㄱ ㄴ ㅁ ㅂ)만 활성화.** 음절 40개로 검증 후 나머지 자음 활성화
- 나머지 10개 자음 타일은 조립판에서 **숨김** 처리 (비활성 회색 아님 — 아이에게 "못 하는 것"으로 보이면 안 됨). 음원이 추가되면 설정 한 줄로 켜지도록 자음 목록을 데이터로 분리
- 파일명은 ASCII 로마자 고정. 한글 파일명 금지 (배포·인코딩에서 깨짐)
- 오디오 누락 시 조용히 넘어가고 콘솔 경고만. 에러 화면 금지

---

## 7. 이중언어 처리 — UI 토글 만들지 않음

4세는 한글도 영어도 못 읽는다. 아이 화면에 **글자를 쓸 일이 없다.**

- **아이 화면:** 자모·글자 외 텍스트 0개. 모든 안내는 아이콘과 음성
- **영어는 부모 화면에만** (진도, 설정, 설명 — P3)
- 언어 토글, 번역 카피, i18n 프레임워크 전부 넣지 않음

## 8. 중단 조건

| 신호 | 판단 |
|---|---|
| 아이가 자모판을 스스로 반복 탭 | P0 통과 → P1 진행 |
| 조립 후 소리 듣고 웃거나 즉시 다시 조립 | P1 통과 → 나머지 100음절 녹음 |
| 가로/세로 레이아웃 이동을 눈으로 따라감 | 교육적 핵심 작동 중 |
| 어른이 유도해야만 터치 / 2~3분 내 이탈 | **중단.** 나머지 녹음하지 말 것 |

## 9. P2 이후 (지금 만들지 말 것)

- 조립한 글자가 실제 단어가 되면 그림 등장 (가 → 가방)
- 받침 추가 (종성 자리)
- 쌍자음 / 복합모음
- localStorage 진도 + 부모 화면 (영어)
- Capacitor로 iOS/Android 패키징
- 할머니 목소리 버전 교체
