# P2 설계: 별(포인트) · 쓰기 길 · 음절 쓰기 · 스티커북

상태: 제안 (승인 후 단계별 구현)

## 0. 벤치마킹에서 가져올 것과 버릴 것

| 앱 | 잘하는 점 | 우리가 다르게 할 점 |
|---|---|---|
| 핑크퐁 가나다 한글 / 엄마까투리 한글공부 | 단원을 마치면 **낱말 카드·단어 카드를 모음** (수집 보상) | 카드가 유료 팩·단원 끝에 묶임 → 우리는 **아이가 만든 글자에서 바로** 단어가 나옴 |
| 우리아이 한글떼기 | 맞히면 사과 → 애벌레가 나비가 되는 **즉각 보상** | "맞히면" 보상 = 틀림이 존재 → 우리는 **틀림 없이** 해낸 만큼 보상 |
| 한글 쓰기 (유치원용) | 화살표·시작/끝 점으로 **획순 안내** | 우리는 이미 있음 (시작점 + 방향 애니메이션) |
| Duolingo ABC | 짧은 단계가 이어진 **길(path)**, 광고·구매 없음 | 길 구조는 가져오되 **연속 출석(streak)·압박은 빼기** |
| Khan Academy Kids | 캐릭터 꾸미기·배지 수집, 보상이 학습과 붙어 있음 | 과한 외적 보상이 흥미를 떨어뜨릴 수 있다는 우려(과잉정당화) → **보상은 학습 행동(쓰기)에만**, 작고 예쁘게 |

우리만의 무기(유지·강화): **이름이 아닌 소리**, **빨강 자음 + 파랑 모음 두 색 조립**, **우리 가족 목소리**, **틀린 답 없음**, **광고·구매·데이터 수집 없음**.

## 1. 원칙

1. **잃는 것이 없다.** 별은 줄지 않는다. 타이머, 연속 출석, 순위, 감점 없음.
2. **숫자보다 그림.** 4살은 "37점"을 모른다. 별은 **유리병이 차오르는 모습**으로 보여준다 (부모용 숫자는 부모 화면에만).
3. **보상은 노력한 행동에만.** 따라 쓰기를 끝냈을 때 별. 타일을 마구 누르는 것엔 별을 주지 않는다 (마구 누르기 = 보상 사냥이 되기 쉬움).
4. **"못 하는 것"으로 보이지 않게.** 아직 안 열린 곳은 회색 자물쇠가 아니라 **선물 상자**로 보인다.
5. **데이터는 기기 안에만** (localStorage). 개인정보 처리방침 그대로.

## 2. 별 (포인트)

- **얻는 법:** 쓰기에서 글자(자모·음절) 하나를 다 쓰면 ⭐ 1개. 같은 글자를 또 써도 매번 1개 (반복 연습도 칭찬).
- **보이는 곳:** 쓰기 화면 왼쪽 위의 **별 병**. 글자를 다 쓰면 별이 글자에서 튀어나와 병으로 날아가고 "띵" 소리(파일 없이 Web Audio로 합성), 병이 조금 차오른다.
- **병이 가득 차면 (별 10개):** 병이 반짝이고 뚜껑이 열리며 **스티커 1장**을 받는다(3장 참고). 병은 비워지고 다시 모은다.
- 부모 화면(녹음 페이지 위)에 총 별 수, 쓴 글자 목록을 숫자로 표시.

## 3. 쓰기 길 (Duolingo ABC식 진행, 압박 없이)

쓰기 탭 첫 화면이 **길**이 된다. 길 위의 동그라미 하나 = 글자 하나.

```
  ㄱ ─ ㄴ ─ ㄷ ─ ... ─ ㅎ      (자음 14, 빨간 동그라미)
  ㅏ ─ ㅑ ─ ㅓ ─ ... ─ ㅡ      (모음 10, 파란 동그라미)
  🎁 음절 길 (자모 24개를 한 번씩 다 쓰면 열림)
  가 ─ 갸 ─ 거 ─ ... ─ 브     (ㄱㄴㅁㅂ × 모음 10 = 40)
```

- 한 번 쓴 글자의 동그라미에는 별이 붙는다. **순서 강제 없음**: 아무 동그라미나 눌러서 쓸 수 있다 (자모 24개 안에서).
- 아직 안 쓴 자모가 있으면 음절 길은 **선물 상자 🎁**로 보인다. 자모 24개를 모두 한 번 쓰는 순간: 축하 애니메이션 + 상자가 열리며 음절 길이 펼쳐진다.
- 현재의 좌우 화살표 쓰기 화면은 그대로 두고, 길에서 동그라미를 누르면 그 글자의 쓰기 화면으로 간다.

## 4. 음절 쓰기 (가, 고, …)

- 만들기 화면과 **같은 두 색 글자**(자음 빨강 + 모음 파랑, 같은 배치)를 크게 연한 안내선으로 보여준다.
- 획순: **자음 획 먼저 → 모음 획** (한국어 표준 순서). 각 획은 지금처럼 시작점 + 방향 애니메이션.
- 판정은 지금의 너그러운 판정 그대로 (자모 획 데이터를 음절 자리로 옮겨 사용).
- 다 쓰면: 음절 소리("가") → **그 글자의 그림 단어 카드**(🎒 가방)가 튀어나오고 단어 소리 → ⭐ 1개. 만들기에서 배운 것과 쓰기가 하나로 이어진다.
- 대상: 만들기에 켜진 자음(지금은 ㄱㄴㅁㅂ) × 모음 10 = 40개. 자음을 더 켜면 길도 자동으로 늘어난다.

## 5. 스티커북

- 스티커 = 40개 음절의 **그림 단어 29개 + 동물 친구 11개** (이미 있는 그림).
- **두 가지 방법으로 붙는다.**
  1. **만들기**에서 그 글자를 처음 조립했을 때 (발견의 기쁨: "다 모아 보자")
  2. 별 병이 가득 찼을 때 선물로 (아직 안 모은 것 중 하나)
- 스티커북 버튼: 쓰기·만들기 화면 왼쪽 위의 책 아이콘. 페이지에는 모은 스티커는 컬러, 아직 없는 것은 **물음표 그림자**(실루엣) — "못 하는 것"이 아니라 "찾을 것".
- 스티커를 누르면 그 단어를 다시 말해준다 (가족 목소리 녹음이 있으면 그 목소리).

## 6. 안 하는 것

연속 출석(streak), 하트·생명, 시간 제한, 순위표, 다른 아이와 비교, 별로 사는 상점·결제, 광고, 알림 푸시.
